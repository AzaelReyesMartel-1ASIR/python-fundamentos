# python-fundamentos

Ejercicios de Python desde cero, hechos como refuerzo antes del Curso de
Especialización en Inteligencia Artificial y Big Data. Cada carpeta corresponde
a un bloque de conceptos, con ejercicios escritos por mí y revisados después.

**Estado:** en progreso.

## Cómo ejecutarlo

Necesitas Python 3. Desde la raíz del repositorio:

```bash
python3 01-variables-condicionales/age.py
```

## Contenido

| Carpeta | Ejercicio | Qué practica |
|---|---|---|
| `01-variables-condicionales` | `age.py` | Pedir un dato con `input()`, convertirlo con `int()`, `if / elif / else` |
| `02-bucles` | `loops.py` | `for` con `range`, par/impar con `%`, acumuladores |
| `03-funciones` | `bank.py` | Funciones con parámetros y `return`, constantes con nombre, pruebas con valores fijos separadas de la entrada del usuario |

## Próximos pasos

- Programación orientada a objetos en Python
- Excepciones, ficheros y entornos virtuales

## Cómo trabajo

Intento cada ejercicio yo solo y después lo reviso, corrigiendo los fallos que
aparecen. Uso la IA para revisar mi código y señalarme errores, no para
escribirlo. El registro de lo que me cuesta y lo que voy aprendiendo lo llevo
aparte, en una bitácora personal.
